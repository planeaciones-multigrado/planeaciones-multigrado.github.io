Una sola rúbrica para el grupo, con un criterio propio para cada grado, simplifica la evaluación formativa en multigrado.

1. Usa los mismos criterios para todo el grupo.
2. Agrega una fila específica para cada grado.
3. Evalúa el proceso, no solo el producto.
4. Comparte la rúbrica antes de empezar.

Esta actividad forma parte de nuestras planeaciones multigrado listas en Word, con PDA oficiales y actividades diferenciadas por grado.
